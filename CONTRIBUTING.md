# 参与贡献 / Contributing

感谢你关注 `rs-godot-edit`。项目目前处于初始化阶段，欢迎通过 Issue 讨论方向，或通过 Pull Request 提交改进。

Thank you for your interest in `rs-godot-edit`. The project is currently in its initial setup phase. Discussion through Issues and improvements through Pull Requests are welcome.

## 提交 Issue / Issues

- 提交前请搜索已有 Issue，避免重复。
- 请清楚描述问题、复现步骤和预期行为。
- 如果问题与环境相关，请附上操作系统、Rust 版本和 Godot 版本。

- Search existing issues before opening a new one.
- Include a clear description, reproduction steps, and expected behavior.
- For environment-specific issues, include your operating system, Rust version, and Godot version.

## 提交代码 / Pull Requests

- 保持改动范围聚焦，并说明改动原因。
- 新增功能应尽量补充测试或验证步骤。
- 不要提交密钥、个人配置、构建产物或编辑器缓存。
- 提交说明应简洁、准确。

- Keep changes focused and explain why they are needed.
- Add tests or verification steps for new behavior where practical.
- Do not commit secrets, personal configuration, build artifacts, or editor caches.
- Keep commit messages concise and descriptive.

## 开发流程 / Workflow

1. Fork 本项目并创建功能分支。
2. 完成改动并进行本地验证。
3. 提交 Pull Request，描述改动内容和验证结果。

1. Fork the repository and create a feature branch.
2. Make the changes and validate them locally.
3. Open a Pull Request describing the changes and verification results.
